## 数据说明

数据文件不纳入 Git（见根目录 `.gitignore`）。本文件记录每份数据的  
来源与获取方式，保证任何人拿到仓库后都能复原 `data/raw/`。

## 目录约定

- `raw/`：原始数据，保持下载时的原样，只读，任何脚本不得改写。
- `interim/`：清洗过程的中间产物，可随时由脚本重新生成。
- `processed/`：最终分析用数据，由脚本生成。

## 数据清单

| 文件（放入 raw/ 后的相对路径） | 来源 | 获取方式 / 链接 | 版本或时间范围 | 下载日期 | SHA256 |
| ------------------ | -- | --------- | ------- | ---- | ------ |
| 待补充                |    |           |         |      |        |

获取数据后，可用 `shasum -a 256 data/raw/<文件>` 记录校验值。

## 大文件方案

超过 Git 仓库合理体积的数据（建议 50MB 以上）不要强行入库，可选：

- Git LFS（仓库内可追踪，但需远端支持）；
- 机构网盘 / 数据平台共享链接，链接与访问方式写在上表；
- 受限数据只需写明申请渠道和审批流程，不要放副本。
